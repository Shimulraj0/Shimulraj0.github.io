# Shimul Raj Das — Portfolio

Live at https://shimulraj0.github.io

Flutter developer portfolio built with Vite + React + Tailwind CSS v4 + Framer Motion. Every app screenshot is a real runtime capture from an Android emulator.

## Source

The source lives in a separate project directory and is built with `npm run build`. This repo contains the compiled `dist/` output served by GitHub Pages.

## Rebuild

```bash
npm install
npm run build
# copy dist/* into this repo root, then commit
```
